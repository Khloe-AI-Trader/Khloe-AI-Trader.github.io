AI Team DRI Bridge

A personal automation tool that lets AI assistants hand structured task requests, acknowledgements and results to each other through a single folder in the owner's own Google Drive.

What the app does

AI Team DRI Bridge runs on the owner's own Windows computer. It connects to the owner's Google Drive to:

  • read request files that the owner's AI assistant places in one designated Drive folder (00_DRI_BRIDGE);
  • write acknowledgement, status and result files back into that same folder;
  • update two coordination documents in that folder (an inbox and an outbox).

The app does not browse, read, or change any other file in the Drive account.

Who uses it

The app is operated by a single individual (the GitHub account Khloe-AI-Trader) for their own Google account. It is not offered to the public and there is no sign-up.

Google user data

The app requests the Google Drive scope https://www.googleapis.com/auth/drive and uses it only inside the designated folder. Details, including storage, sharing and deletion, are in the Privacy Policy.

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
