Privacy Policy

Last updated: 2026-10-18

1. Who we are

AI Team DRI Bridge ("the app") is a personal tool operated by one individual, the owner of the GitHub account Khloe-AI-Trader, for their own Google account. The app has no other users and no public sign-up.

2. Google user data the app accesses

With the owner's consent, the app requests the Google Drive scope https://www.googleapis.com/auth/drive. In practice it works only inside one folder that the owner selects with the Google Picker (named 00_DRI_BRIDGE). Within that folder it:

  • lists and reads request files and two coordination documents (DRI_INBOX, DRI_OUTBOX);
  • creates small JSON files for dispatch, acknowledgement and result records;
  • updates the outbox document with status entries.

The app does not read or modify files outside that folder, does not access Gmail, Calendar, Contacts or any other Google service, and does not collect profile information beyond what Google's sign-in returns to complete authorization.

3. How the data is used

The data is used only to run the app's single feature: exchanging task requests, acknowledgements, status and results between the owner's AI assistants. It is not used for advertising, profiling, or any purpose unrelated to that feature.

4. Where the data is stored

  • Authorization tokens (including the refresh token) are stored in a file on the owner's own Windows computer. They are not uploaded anywhere and are never published.
  • Copies of request, acknowledgement and result files are kept in a local folder on the same computer for record keeping.
  • The app does not run a public server and has no central database.

5. Sharing and transfer

We do not sell Google user data and do not share it with advertisers, data brokers, or the public.

The only Google Drive content that leaves the owner's computer is the text of task request files that the owner's own AI assistant places in the designated folder. The app reads these requests and passes limited fields to two AI providers, solely to carry out the task the owner asked for:

  • OpenAI (API, api.openai.com): to review the status of a task, the app sends a short record containing the request ID, task ID, status, authority class, target agent, an optional blocked reason, and the task's summary text (up to 4,096 characters) taken from the request file. The app does not send other Drive files, document bodies, file lists, or credentials in this request. The request sets OpenAI's store option to false; this is a request setting and does not mean OpenAI retains nothing.
  • OpenAI Codex and Anthropic Claude (command-line agents run on the owner's computer): when the owner's assistant assigns a task to one of these agents, the task's ID, category, priority, summary, constraints and related references from the request are given to that agent, which sends them to its provider to produce a result. Fields whose names suggest credentials are redacted first. The agents are started in read-only, non-persistent modes, and while working on a task they may also read local files that their read-only access allows, including local copies of request and result records; excerpts of what they read may be sent to the provider as part of producing the result. The agent's result is then written back to the designated Drive folder.

These providers act on the owner's own accounts and instructions. If and how long each provider retains the data, and whether it may use the data for its own purposes, is governed by the owner's agreement and account settings with that provider and is not controlled by this app. No Google user data is transferred for any other purpose, except where required by law.

6. Limited Use

The app's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements. Humans do not read the data, except with the owner's consent, for security purposes, to comply with law, or where the data is aggregated and anonymized for internal operations. The app itself does not use Google API data to develop, improve or train generalized AI or machine-learning models, and it sends such data to the AI providers described in section 5 only to carry out the task the owner requested. This app cannot control what those providers do under the owner's own agreements with them.

7. Retention and deletion

  • You can revoke the app's access at any time at myaccount.google.com/permissions.
  • Deleting the local token file on the owner's computer removes the stored authorization.
  • Files in the Drive folder belong to the owner and can be deleted from Google Drive at any time. Local copies can be deleted from the owner's computer.

8. Security

Credentials are kept only on the owner's computer, are not included in any public repository or web page, and are not written to logs. The app requests the access it needs and nothing more.

9. Changes

If the app's use of data changes, this page will be updated and the date above revised.

10. Contact

Questions or deletion requests: open an issue at github.com/Khloe-AI-Trader/Khloe-AI-Trader.github.io/issues. Do not post credentials or personal data in an issue.
